Audit log

Nhật ký mẫu không được giả lập. Sự kiện thật sẽ được cung cấp từ backend và GitHub Actions.

Chưa kết nối audit event sourceKhông có sự kiện nào được đưa ra như thể là log thật. Cần tích hợp GitHub Actions API, server audit table và event pipeline; ghi thời gian UTC, nguồn, trạng thái và mã tham chiếu.
Không ghi token, mật khẩu, OTP, nội dung nhạy cảm hoặc thông tin liên hệ đầy đủ vào log. Hạn chế quyền đọc log và đặt chính sách lưu trữ.
